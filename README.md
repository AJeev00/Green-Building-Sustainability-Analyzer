# GreenAsset — Green Building Sustainability Analyzer

A scenario-based Streamlit tool for exploring building energy demand, operational carbon, water use, solar PV potential and rainwater harvesting.

## Features
- Editable building and occupancy assumptions
- Energy and operational carbon scenario estimates
- Solar PV contribution estimate
- Rainwater harvesting potential
- Water-demand scenario comparison and visual summaries

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Scope and limitations
Outputs are indicative scenario estimates, not a certified energy audit, whole-life carbon assessment or detailed engineering design. Emission factors and assumptions should be replaced with current, location-appropriate and project-verified data before use.

## Deployment
Deploy `app.py` on [Streamlit Community Cloud](https://share.streamlit.io/).
